# responsive-profile-cards-
Responsive profile cards built with HTML Bootstrap and CSS, featuring circular profile images, star ratings, and interactive-style buttons.
## About
A profile card project featuring a clean and attractive design.

## Features
- Circular profile images
- Star rating display
- Read More and Subscribe buttons
- Responsive card layout

## Technologies Used
- HTML5
- CSS3
- Bootstrap

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
